# Agent Skills & Domain Knowledge Router

このファイルは、全プロジェクト共通の基本スキルと、専門領域（ドメイン）ごとの知識ファイルをルーティングするためのインデックスです。

---

## 1. 共通スキル (Common Skills)

* **参照ファイル**: `knowledge/protocol.md`
- **対象**: すべてのプロジェクト
- **内容**: AIエージェントの基本行動規範（全18箇条）、マイクロコミット、リファクタリングの禁止、デザイン要件など。
- **指示**: いかなる作業を開始する際も、各ドメイン知識と併せて必ずこのプロトコルを読み込み、厳格に順守すること。

---

## 2. ドメイン知識 (Domain Knowledge)

作業中のプロジェクトの性質に合わせて、以下のドメイン知識ファイル（`knowledge/` フォルダ内）を読み込み、専門スキルを適用してください。

### 🎲 ロト関連プロジェクトの場合
**参照ファイル**: `knowledge/lottery.md`
- **対象プロジェクト例**: 排除予想システム、RIVER_FLOW_PUBLISHERなど
- **内容**: 排除理論、7指標、川分析、バックテスト等の専門ロジック

### 🤖 AI開発関連プロジェクトの場合
**参照ファイル**: `knowledge/ai-development.md`
- **対象プロジェクト例**: AI開発コンテキスト管理ツールV2、BaseKitなど
- **内容**: AI開発フロー、コンテキスト最適化、SKILLS/RULES設計、MCP連携

### 🏢 業務システム関連プロジェクトの場合
**参照ファイル**: `knowledge/business.md`
- **対象プロジェクト例**: 業務用SNSシステム、複式簿記システム、個人業務効率化ツールなど
- **内容**: 認証認可、CRUD、DB設計、UI/UX設計、セキュリティ

---

## 運用ルール

1. AIエージェントは作業開始時に、現在のプロジェクトがどのドメインに属するかを判定すること。
2. 判定したドメインに対応する `knowledge/*.md` を読み込み、その指示に従うこと。
3. 専門的なロジックやルールは、この `SKILLS.md` に直接書かず、各ドメイン知識ファイル（`knowledge/*.md`）に追記すること。
4. **【能動的提案の義務】** AIは開発中に「他のプロジェクトでも再利用できる有益なルール・設計方針（ベストプラクティス）」や「新しいスキル」を発見した場合、自律的に抽出し、ユーザーへ「これをドメイン知識（または共通スキル）に追記しませんか？」と提案すること。
